# 图片编码器张量并行：image_encoder_tp_size

## 1. 验证对象与结论

`image_encoder_tp_size`控制图片编码器由几张NPU共同计算：1表示一张，2表示两张按规则分担同一次图片编码，即张量并行（TP）。它不表示整个Ming模型只用这些卡，回答阶段还使用另外的计算资源。任务清单沿用此参数名；所测版本的配置键及命令行参数分别为`image_encoder.tp_size`、`--image_encoder.tp_size`。

**参数结论（2026-11-17）：`image_encoder_tp_size` 在 NPU 上支持。在验证该参数的调用链路时，发现了 Ming-Omni 的媒体特征对齐、模态路由问题，以及撤回后媒体输入恢复的风险，已提交 Issue #4142 跟踪。本参数的验证与问题反馈工作已完成。**

早期 Ming 曾漏传 TP 配置，后续核查的官方 main `5f03f7e9` [已补齐该配置传递](https://github.com/sgl-project/sglang-omni/blob/5f03f7e9/sglang_omni/models/ming_omni/components/image_encoder.py#L146)。以下模型问题不属于 TP 参数本身不受支持，单卡请求也可能受影响：

- **媒体特征对齐：**新请求命中前缀缓存后，读取媒体特征时没有跳过缓存已覆盖的行，可能把前面的图片特征填到后面的位置。
- **模态路由：**检查点提供了图片、音频专用的专家路由，原实现却使用文字路由，未按输入模态选择对应权重。
- **撤回恢复风险：**请求撤回后重新处理输入时，媒体输入可能未恢复、旧读取进度可能未清除。定向测试已复现异常，真实调度器下的端到端稳定复现仍待验证。

上述问题已提交 [Issue #4142](https://github.com/sgl-project/sglang-omni/issues/4142)，原修复 [PR #3376](https://github.com/sgl-project/sglang-omni/pull/3376) 已关闭，保留实现和验证记录供后续跟进。早期 TP 及执行条件下的答案差异继续记录在 [Issue #2737](https://github.com/sgl-project/sglang-omni/issues/2737)。

下文保留各版本的精度、性能与已知退步。参数支持结论不代表这些模型问题已经解决，也不将历史候选的 TP2 结果当作当前 main 的完整服务验收。

### 历史方案与验证结果

以下保留 2026-10-15 报告对应的早期算法与实测结论。TP2 完整请求及 TP2/4/8 局部编码结果只支持该冻结候选的所测路径；TP4/8 没有完整 900 题服务评测，数据不转用于后续 #3376 或当前 main。

| 实测版本中的改动 | 问题归属与作用范围 |
| --- | --- |
| TP初始化传入实际tp_size | 早期Ming接入修复；后续核查的main已具备配置传递 |
| 缓存前缀覆盖部分图片时，从剩余图片特征继续读取 | Ming多模态输入修复，适用的单卡请求也受影响，不是TP参数独有缺陷 |
| 按检查点配置使用图片、音频专家路由 | Ming模型实现修复，不只影响图片TP，也未限定NPU |
| NPU且TP>1时的新图片编码分片算法 | 项目选定的数值一致性方案，使用真实权重分片、临时完整形状矩阵及通信调整；有计算成本，尚未证明是基本TP可用不可缺少的最小修改 |

早期 PR #2427 没有修改共享CANN、TorchNPU或SGLang矩阵内核源码。接入、特征/路由修复和数值算法应分别审查；本报告保留当时项目选定的新算法及其测量结果，不将其成绩转移给移除算法后的未测版本。

**所选版本的内容验收与性能：**TP2完成900/900题，无请求失败或不可解析回答，确定性审计答对538/900。历史单卡正确的固定532题中保留524题、退化8题，另新增14题正确。按本项目确认的质量范围接受，8道退化及原始失败仍单列保留，不用新增正确题抵销。新算法双卡局部编码耗时约为单卡2.72倍，完整服务吞吐、首字及总响应延迟未测，不能用旧算法的整服务性能补充。

**独立跟踪的问题：**另一次同环境单/双卡八题对照中，两组答案相同、均为1/8正确，对应图片特征、注入数据和首两步生成分数也相同。因此，历史8题退化尚未全部解释，不能统一归为“多卡矩阵算子错误”。Issue #2737记录8个病例的答案、版本与执行条件，继续跟踪差异原因；完整原始输入、结果及诊断材料保留在本地证据归档，未公开上传，可按授权提供。

**历史源码身份与提交状态：**PR #2427由基线`c508f35afd556a3d588c6d757932e8b4ce2f6d8d`更新至`da3da32dcf3fdc2be41acb96c2b4b6f604739342`。更新涉及3个产品文件及匹配测试，产品计算逻辑与完整900题冻结源码等价，测试仅作等价导入和格式整理。该 PR 包含本文早期新算法；截至 2026-11-17 仍开放、未合并，作为历史方案保留。

新旧全量运行不是仅改变算法的严格对照，分数变化不能全部归因于新算法；本报告按选定版本报告观察结果。图配置、各项测试及覆盖边界见下文。
