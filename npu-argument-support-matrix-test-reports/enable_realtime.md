# 实时语音会话：enable_realtime

## 1. 验证对象与结论

`enable_realtime`控制是否开放实时语音会话入口，客户端通过该入口提交音频并接收文字及生成声音。SGLang-Omni已有这一入口，Qwen3-Omni-30B-A3B-Instruct也已有语音输出能力。本报告验证该能力在所测NPU环境中的可用性。

**参数结论：NPU需要；既有实时入口在完成所测NPU适配、并采用匹配的Qwen语音实现后，开关控制及完整会话功能验证通过。本次没有新建实时参数，也不将全部模型修复计为参数开发。**

**参数直接证据：**关闭参数时连接被拒绝（HTTP403）；开启后，匹配v4完成1088/1088条会话及内容评分。共享通信层按真实设备类型识别NPU张量，是本次NPU运行路径的适配。该结果针对下述匹配源码，不能据已有入口推定未修复环境也已通过。

**实测环境的内容验收：**生成声音经ASR识别后，相对服务返回文字的词错率（WER）为254/13236，即1.92%，按本项目确认的质量范围接受。ASR是将声音识别成文字的工具；WER统计替换、删除和插入的词数。其他评分、逐条差异和失败病例均保留；接受该质量范围不等于每句话均正确，也不等于每个词差都是框架错误。GPU报告只能作为背景参考，不能因数值处于其区间便声称严格的GPU/NPU等价，具体口径见第二节。

**独立跟踪的问题：**病例0919返回文字以“Like other lavenders”开始，Qwen-ASR及Whisper均把生成音频识别为“Unlike other lavenders”；原种子`1094055237`可逐字节复现该音频。其最终原因尚未确定，不能定性为实时参数、模型权重或底层矩阵算子错误。190条声音与文字存在词差的记录均保留第二识别器复核，其中也包含形式差异、专名及识别器分歧。

Issue #2738已公开文字证据、评分口径及源码引用；原始录音、生成音频和完整材料保留在本地证据归档，未公开上传，可按授权提供。问题仍未解决，由issue继续跟踪，不以其存在自动否定已完成的参数功能验证，也不以总体分数将具体失败销账。

## 2. 测试用例

先检查开关是否控制入口，再检查完整会话是否结束、数据是否按实际内容传递，最后分别评估返回文字、生成声音及时间。声音可以播放、接口返回成功，都不能代替内容评分。使用相同识别器评估原录音，另对疑点使用第二识别器，保留评分器自身误差的影响。

### 2.1 环境信息

| 项目 | 实测条件 |
| --- | --- |
| 模型与平台 | Qwen3-Omni-30B-A3B-Instruct；151服务器昇腾NPU |
| 软件与依赖 | SGLang 0.5.20、PyTorch/torch_npu 2.10、Transformers 5.12.1，使用匹配采样整数补丁 |
| 代码版本 | 冻结v4源码`prompt_hidden_product_v4_20261008_source`；等价提交至PR #2426，并配套SGLang PR #43825 |
| 配置 | 默认提前启动开启；图捕获、重叠调度关闭；缓存页大小128 |
| 音频协议 | 输入16 kHz PCM16，输出24 kHz；输入和输出身份已核对 |
| 内容数据 | 英语语音复述；1088请求、666条不同录音、13232参考词；并发4 |
| 性能数据 | 同一固定20条，串行和并发4各测一组；首音从`response.created`事件开始计时，不包含此前全部输入/VAD时间 |
| 评分 | 全量Qwen-ASR；190条非零声音/文字差异另有Whisper对原声与生成声的复核记录 |

完整证据包为`交付补测_20260929/prompt_hidden_v4_full_evidence_v2_20261008.tgz`，9499项原件已核验，SHA256为`35fc2354e3bdf15f6e3a18f0eac0ba4e256632e5bf2dc51d730fb475b9498f23`。独立复核位于同级`v4_内容独立审查_20261008/`。路径相对随附项目证据根目录；冻结源码、依赖修复、提交SHA及等价核对记录共同构成版本依据。原始证据包本地保留，未作为issue公开附件。

| 用例名称 | 用例步骤 | 预期结果 | 实际结果 |

| 返回文字质量 | 服务文字与原输入参考逐词比较 | 记录完整词差 | 175/13232词编辑，约1.32% |

5618秒是该固定全量任务的生成阶段墙钟时间，不作为最大服务吞吐。20条测试用于基础延迟对照，未建立饱和吞吐或跨硬件加速结论。

[GPU PR #2474](https://github.com/sgl-project/sglang-omni/pull/2474)报告H100、SeedTTS-EN上的trimmed WER 1.62%–2.06%。其数据、并发和裁剪口径与本文不同，只作背景参考，不能作为严格GPU/NPU等价证明。本报告的通过依据是功能证据及本项目确认的质量接受范围。
